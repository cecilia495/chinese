# 中文伴 V2.0 实施记录

## 现有网站与改动

GitHub Pages 访客版保留已有的 HSK 1–3 餐厅课、图片、预录音频、正常及慢速播放、录音回听、听力题和引导式点餐。在首页加入主题学习、情景口语和我的学习入口。自由交流标为开发中。主题页按领域浏览，支持中英文名称搜索与已开放等级筛选。目前开放一个主题，其他 47 个是待开发的教学分类。主题 ID 是站内教学标识。

现有餐厅课仍为四个阶段。听力题、录音和引导式点餐沿用已有验证。访客学习页读取当前标签页的会话记录，显示各等级完成环节、点餐任务完成情况、完成次数和复习表达。登录、教师功能和数据库位于独立的 Next.js 完整版。

## AI 与语音部署

GitHub Pages 负责静态资源。完整版已有餐厅回复及语音端点，可在支持 Node.js 的 HTTPS 环境接入真实服务。优先在同源服务中运行课程前端和接口。如要让 GitHub Pages 调用独立后端，需要为确切的 Pages 来源启用 CORS，并配置身份验证、限流和额度。服务端保存 Coze 或模型、ASR、TTS 及评测凭证，并限制请求大小、上传格式和对话轮数。浏览器使用 HTTPS 申请麦克风权限。接口分别处理识别失败、网络超时、额度不足和音频播放失败，允许学生重试。发音评分由支持声学评测的服务分析实际音频。当前 GitHub Pages 访客版提供预录音频和录音回听。
