# 当前架构与目标边界

- GitHub Pages 由 `gh-pages` 提供，访客源码来自 `visitor-source`，采用 Next.js 静态导出及 `/chinese` 子路径。课程音频、词汇和课程页面可以独立于后端使用。
- `main` 保存可下载归档。工作区完整版提供练习、语音、身份认证、学习和教师 API，以及数据库迁移。应先复用并验收这些入口。
- 访客偏好保存在 localStorage，课程进度保存在当前标签页的 sessionStorage。回访入口根据实际会话导航，跨端同步需要登录及数据库。
- 目标部署由 HTTPS 应用服务持有数据库及模型凭据，建议同源提供练习页面与 API。教师与内容审校操作走服务器权限检查和审核记录。
